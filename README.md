# Java-projects
My old Java projects (most are discord bots)

Game Demo: A concept demo for a game that I created that aims to show the player the key game mechanics like the actions that a player can take during turns. The player fights against a computer controlled opponent that runs on a simple algorithm that's based off of the player's previous actions.

Arknitebot: Old Discord bot I created back in grade 9/10 that sends information about all the canonically dead characters in Arknights. Additionally there are 2 sillier commands, one I made to keep track of the current money spent by my robotics team and another that simulates the gacha mechanism in Arknights.

Valbot: Another Discord bot I created that sends information about Valorant's competitive scene, mainly upcoming/ongoing/past events and information about competitive teams. All information is scraped from VLR.gg through a program that I also wrote for this project.
