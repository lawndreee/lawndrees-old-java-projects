VERY old discord bot project that functioned both as an Arknights wish simulator and also a Arknights dead npcs database (mostly these although I did add some weird commands in as well).

Features 5 commands that are all slash compatible:  
  &ensp;currwish: Wishing simulator for the current banner (No longer updated, so the banner is from quite a while ago)  
  &ensp;meow: Test command  
  &ensp;profile: Features a mandatory name input that will send the profile of a dead npc in Arknights if the name inputed exists in the system. Returns information such as name, photo, description, first and last appearance and how they died.  
  &ensp;quote: Features a mandatory name input that will send the last said line of a dead npc in Arknights if the inputed name exists in the system.  
  &ensp;vexfunds: Ignore this command; it was a way goofy way for me to track the total spendings of my VEX mentor back in highschool.
