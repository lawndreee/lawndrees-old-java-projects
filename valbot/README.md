Valorant Esports discord bot project that web scraped vlr.gg for information using jsoup. Currently a scrapped project as I plan on making a new version that uses vlr.gg's REST API instead.

Bot works with both slash commands and regular ! commands. It features the following 5 commands:

compevents: displays a list of recently completed events, with buttons to toggle through. Displays information such as date range of the event, location, icon image of the event.
currevents: displays a list of currently ongoing events, same format and information as above.
upevents: displays a list of upcoming events, same format and information as above.
team: This command hasn't been set yet (displays null), but it gives the user the ability to search for certain teams through their name with an optional tag for the region which will display a list of teams from that region. If the call is left blank, then it will return a list of all currently active teams.
meow: Test command to see if the bot is active and working.
